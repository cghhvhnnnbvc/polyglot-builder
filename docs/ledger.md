# 资源台账

资源多了以后，最难的不是构建，而是**记住"哪个文件是什么、放在网盘哪里、密码多少"**。
资源台账就是为解决这个问题设计的：它是存在本地的**资源目录**（JSON 数据 + 可双击浏览的 HTML 查看页）。

> ⚠️ 台账里的 RAR 密码是**明文**保存的。台账文件（`.json` 与 `.html` 两个）只应留在你自己的电脑上，
> **不要上传网盘、不要发给别人、不要截图分享**。（仓库 `.gitignore` 已排除它们）

## 台账是什么

台账由**两个文件**组成（同目录同名，只有后缀不同）：

| 文件 | 角色 | 说明 |
|------|------|------|
| `资源台账.json` | **唯一数据源** | 纯数据 `{"version": 1, "records": [...]}`；标准格式、原子写入（临时文件 + 替换），可备份/diff/迁移 |
| `资源台账.html` | **自动生成的查看页** | 每次保存由 JSON 重新生成；自包含（数据内嵌），双击浏览器即开 |

为何这么分：

- **读写不再脆弱**：数据不用从 HTML 里用正则抠，也不怕被记事本/插件误伤
- **查看器可升级**：以后改进网页界面，旧数据下次保存就自动用新界面渲染（单一 HTML 方案做不到）
- **HTML 是衍生物**：不小心删了也没事，程序会从 JSON 重建；拷到手机也只需拷这一个 HTML

> 旧版单文件 HTML 台账（v1.1 定稿前的早期实现，未正式发布）**会被自动迁移**：
> 读数据 → 写 JSON → 旧 HTML 改名为 `.html.bak` 保留 → 生成新查看页。

## 记录哪些字段

| 字段 | 来源 | 说明 |
|------|------|------|
| 资源名称 | 手工填写 | 这是什么资源，如"某游戏整合包" |
| 文件名 | 构建后自动填入，**可手改** | 构建产物文件名；手动新增记录时自行填写 |
| 大小 | 构建后自动填入，**可手改** | 产物文件大小 |
| 记录时间 | 构建后自动填入，**可手改** | 留空则保存时自动填当前时间 |
| 网盘 | 手工选择 | 百度网盘 / 夸克网盘 / 阿里云盘 / 迅雷云盘 / 115 / 天翼 / OneDrive / Google Drive / 其他 |
| 网盘位置 | 手工填写 | 上传到网盘的哪个目录，如 `/我的资源/2026/游戏` |
| 分享链接 | 手工填写 | 可选，台账里会渲染成可点击链接 |
| 提取码 | 手工填写 | 可选，网页里可一键复制 |
| RAR 密码 | 手工填写 | WinRAR 解压密码；网页里默认遮罩，点"显示"才可见 |
| 备注 | 手工填写 | 可选 |

## 怎么用

### 图形界面

1. **主界面右上角的「资源台账」按钮**（浅蓝色，与标题同一行）：
   - 台账不存在时引导你选位置创建（选的是 **`.json` 数据文件**，同名 `.html` 查看页自动生成）
   - 已存在则打开**台账管理窗口**
2. **台账管理窗口**（增删改都在这里）：
   - 列表展示全部记录 + 顶部搜索框实时过滤
   - **新增记录** / 选中后**编辑**（也可直接双击行）/ **删除**（会二次确认）
   - 改动**即时写回** JSON 数据文件并重新生成 HTML 查看页，无需额外保存
   - 「在浏览器中打开」查看网页版（适合浏览/复制/导出）
3. **构建成功后**会弹出“记入资源台账？”——选“是”弹出记账窗口，
   文件名/大小/时间已自动填好（**仍可修改**），你只需补资源名称、网盘位置、RAR 密码
   （手动新增时这三项为空，全部字段都可自行填写）
4. 你选过的台账位置会被记住（存在程序目录的 `ledger_config.json`），下次启动直接沿用

> **为何编辑/删除在程序窗口而不在网页里？**
> 浏览器打开的本地页面（`file://`）**没有写本地文件的权限**：
> File System Access API 在 `file://` 下不可用，Firefox/Safari 也完全不支持。
> 所以网页版定位为**只读查看器**（搜索/筛选/复制/导出 CSV），
> 所有修改统一由程序完成，可靠且与浏览器无关。

### 命令行

```bash
python polyglot_build.py video.mp4 game.rar -o out.mp4 ^
  --ledger 资源台账.json ^
  --ledger-name "某游戏整合包" ^
  --ledger-netdisk "百度网盘" ^
  --ledger-location "/我的资源/2026/游戏" ^
  --note "第一次上传"
```

（传旧版 `--ledger 资源台账.html` 也能用：会自动规范化为 `.json` 并迁移旧数据）

- 不加 `--ledger` 时 CLI 完全不产生台账文件（无副作用）
- **RAR 密码**：在交互式终端下会用 `getpass` 询问（输入不回显、不进 shell 历史）；
  静默模式（`-q`）或非交互环境（CI/脚本）下密码留空，可事后在台账网页里补
- 记账失败不会影响构建结果，只在日志里警告

## 网页查看器能做什么

网页版是**只读查看器**（修改请用程序里的台账管理窗口）：

- **搜索**：按资源名称/文件名/网盘位置/备注等任意字段实时过滤
- **按网盘筛选**：下拉只看某个网盘的资源
- **密码遮罩**：默认显示圆点，点"显示"才明文，避免旁人瞥见；每条密码可一键复制
- **一键复制**：提取码、文件名
- **导出 CSV**：带 UTF-8 BOM，Excel/WPS 打开中文不乱码，便于备份或迁移
- **计数**：右上角显示总条数与当前筛出条数

## 备份与恢复

| 文件 | 是否需要备份 | 说明 |
|------|--------------|------|
| `资源台账.json` | ✅ 唯一数据源 | 复制它 = 备份全部记录 |
| `资源台账.html` | ❌ 可不备 | 衍生物, 程序会从 JSON 自动重建; 带上它可在没装本程序的机器上直接用浏览器查看 |
| `ledger_config.json` | ❌ 不用 | 只存"上次使用的台账路径"; 换机器后程序默认找自己目录下的 `资源台账.json` |

**恢复方式** (任选其一):

1. 把备份的 `资源台账.json` 拷回程序目录 (保持默认文件名), 下次打开自动识别
2. 点「资源台账」按钮 → 在文件选择框里**直接选中那个已有的 .json** → 程序会直接使用它
   (绝不会清空覆盖; 此行为有回归测试守护)

**旧版台账**: 若你手里是 v1.2 之前的单文件 HTML 台账, 把它放到程序目录且 JSON 不存在时,
程序会自动迁移: 读数据 → 写 JSON → 旧 HTML 改名 `.html.bak` 保留 → 生成新查看页。

> ⚠️ 备份文件里含明文 RAR 密码, 请当密码本保管: 加密 U 盘 / 加密压缩包, 不要裸存网盘。

## 安全建议

- 台账文件放在**不随网盘同步**的目录（如 `D:\我的台账\`）
- 定期备份 `.json`（它就是全部数据）到加密的 U 盘或加密压缩包
- 若担心明文密码，可把整份台账再放进一个加密 RAR 里保存
- 后续版本可考虑"主密码加密台账"（用 Windows DPAPI 或主密码派生密钥保护密码字段）
